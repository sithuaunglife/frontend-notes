# Testing

## Facts
- Vitest/Jest/Bun Test = test code and logic.
- React Testing Library = test React UI behavior.
- Playwright/Cypress = test the application as a user in a browser (E2E testing).
- Next.js can be used with different unit-testing frameworks.
- npm is a package manager, so it can install any compatible testing framework.
- Unit testing, React component testing, and E2E testing are different types of testing and serve different purposes.
